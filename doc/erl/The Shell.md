# The Shell
## [[erl/erl|erl]]

In [[Erlang]]
- you can test most of your stuff in an REPL (emulator);
- it will run your scripts when compiled and deployed, but 
- it will also let you edit stuff live.

you should see text like this:
```
Erlang/OTP 25 [erts-13.1.5] [source] [64-bit] [smp:8:4] [ds:8:4:10] [async-threads:1] [jit:ns]

Eshell V13.1.5  (abort with ^G)
1> Ctrl+C Ctrl+D
```
