# popular apps written in [[Erlang]]

## IM

- **WeChat:**
	- This major messaging app, popular in Asia, also uses Erlang.

- **WhatsApp:** 
	- The messaging platform's backend heavily relies on Erlang, enabling it to handle a massive number of concurrent users and messages with high availability.

- **Facebook Chat**:
	- Erlang was used to power the backend of Facebook's chat service, handling over 100 million active users.

- **ejabberd:** 
    - An open-source XMPP (Extensible Messaging and Presence Protocol) server, Ejabberd is written in Erlang and is a popular choice for instant messaging and chat applications.

## Infrastructure & Backend Systems

- **RabbitMQ:** 
    - A widely used open-source message broker, RabbitMQ, is implemented in Erlang. It provides robust and scalable messaging capabilities for various applications.

- **Heroku**:
	- The cloud platform-as-a-service company uses Erlang for its routing mesh.

- **CouchDB:** and **Riak**
	- This "schema-less" document-oriented database, known for its scalability and fault tolerance, is also built with Erlang.

- **Amazon SimpleDB**:
	- Amazon used Erlang to implement SimpleDB, a part of its Amazon Elastic Compute Cloud (EC2) services

## [[telecom]]

- **Telecom Providers**:
	- Major telecommunications companies like [[Ericsson]], [[T-Mobile]], and EE have used Erlang in various core services such as advanced call control, [[SMS]], and authentication systems.

## [[fintech]]

- **Goldman Sachs:** 
    - The financial institution uses Erlang in certain systems, particularly where high performance and reliability are critical for handling financial transactions and data.
    
- **Klarna:** 
    - This Swedish fintech company, known for its payment solutions, also utilizes Erlang in its backend infrastructure.

## misc

- **Wings 3D:** 
    - An advanced subdivision modeler used for creating and texturing polygon meshes, Wings 3D is an example of an interactive desktop application that uses Erlang.
