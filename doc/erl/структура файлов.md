# структура файлов проекта на [[Elixir]]

```
web/
    mix.exs
    lib/
        web/
            application.ex
        web.ex
    test/
        test_helper.exs
        web_test.exs
    config/
        dev.exs
        config.exs
    src/
        hello.erl
    .formatter.exs
    .gitignore
    README.md
```

- `mix.exs` [[mix-проект]]
- `lib/` исходный код на [[Elixir]]
- `src/` исходный код на [[Erlang]]
- `config/`	[[конфигурирование]]
- `test/` [[unit-тест]]ы
- `.formatter.exs` настройки для [[mix format]]
