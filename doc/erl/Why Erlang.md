# Why [[Erlang]]?

> Erlang’s runtime architecture perfectly matches that of evolutionary and neurocomputational systems.

- Everything is concurrent 
- and distributed, 
- each process =neuron is an independent and concurrent element
- which processes its information along with over a hundred billion other neurons
- in a computer local cluster (provided off-the-shelf)
- with async message passing as a cross-neural activation mechanism

> because there is such a direct match, we will not have to worry as much about how to first map these distributed and complex systems into a form that other programming language uses.
