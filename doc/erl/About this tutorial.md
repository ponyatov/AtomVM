# About this tutorial

This is the beginning of Learn You Some Erlang for Great Good! Reading this tutorial should be one of **your first steps in learning [[Erlang]]**

 I began growing the idea of writing this after reading Miran Lipovača's Learn You a Haskell for great Good! (LYAH) tutorial; I thought he did a great job making the language attractive and the learning experience friendly.

This book thus wants itself to be a way to learn Erlang
- for people who have basic knowledge of programming in imperative languages (such as C/C++, Java, Python, Ruby, etc) 
- and may or may not know functional programming
