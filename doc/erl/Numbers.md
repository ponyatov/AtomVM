# Numbers

> expressions have to be terminated with a period followed by whitespace (line break, a space etc.)

**Integers** and **floating** values are pretty much the only types of data Erlang's mathematical operators will handle transparently for you.

- `div` = `//` in Python
- `rem` = `%`

integers in other bases than base 10:

- `base#value`
- base is in the range 2..36
